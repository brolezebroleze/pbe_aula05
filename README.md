  Descrição do Projeto: <br>
  A ideia é criar um sistema onde pode-se fazer o inventário de periféricos de uma determinada instituição, onde se tem opções de listar todos, fazer busca por ID especifico, criar e excluir.
  <br></br>
  </div>
  
  ## Como rodar o Servidor?
  Clone este Repositório
  ```
 git clone https://github.com/brolezebroleze/pbe_aula05
 ```
Abra a pasta no [Visual Studio Code](https://code.visualstudio.com) </br>
⮩ Rode no Terminal do VS (Crtl + J) </br>
```
npm run dev
``` 

⮩ Baixe a Extensão [Thunder Client](https://www.thunderclient.com/)
</br>
⮩ Altere os Dados como desejar, (PUT para Atualizar, POST para Criar, DELETE para apagar e GET para listar)
